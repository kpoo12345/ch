# 방송장비 마스터 (Broadcast Equipment Master)

마이크·믹서·스피커·스위처·OBS의 **신호 흐름(Signal Flow)** 과 **트러블슈팅**을 직접 만지며 배우는 웹 시뮬레이션 교육 게임입니다.
React + Tailwind CSS + lucide-react로 UI를, Three.js(React Three Fiber)로 **3D 스튜디오**를 만들었습니다.

## 3D 스튜디오

- 마이크 스탠드·진행자·아날로그 믹서·X32 디지털 믹서·액티브 스피커·카메라(삼각대)·ATEM 스위처·PC 모니터를 입체로 모델링
- 게임 상태가 그대로 보입니다: GAIN·EQ 노브 회전, 페이더 위치, LED 레벨 미터, MUTE/48V 램프, 스피커 콘 진동과 음파, 하울링 시 빨간 파동과 피드백 루프 표시, 카메라 탈리(PGM 빨강/PVW 초록), ATEM 버튼 불빛, X32 라우팅 화면, OBS 모니터 화면, 벽의 ON AIR 사인
- 케이블은 단자에서 바닥으로 늘어지는 입체 케이블로 그려지고, 신호가 흐르면 빛 입자가 케이블을 따라 이동합니다
- 마우스 드래그로 회전, 휠/핀치로 확대, 장비 더블클릭 또는 "가까이 보기" 버튼으로 해당 장비 클로즈업
- 위쪽 탭에서 기존 2D **배선도** 보기로 전환할 수 있습니다

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `src/game/engine.js` | 장비·케이블 정의, 스테이지 데이터, 신호 계산 엔진 (2D·3D 공용) |
| `src/game/Studio3D.jsx` | 3D 스튜디오 장면 (장비 모델, 케이블, 효과, 카메라) |
| `src/BroadcastMasterGame.jsx` | 게임 UI (미션, 장비 제어 패널, 인벤토리, 로그, 2D 배선도, 모달) |

## 실행

```bash
cd broadcast-master
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/index.html 단일 파일로 빌드 (JS·CSS 인라인)
```


## 스테이지

| 스테이지 | 주제 | 배우는 것 |
| --- | --- | --- |
| 1. 소리의 시작 | 기초 음향 | 장비 배치, XLR 케이블, 마이크 → 믹서 → 스피커 신호 흐름, 전원 켜는 순서 |
| 2. 피드백 제어 | 심화 컨트롤 | 게인 스테이징, 페이더, EQ 컷, 스피커 배치로 하울링 잡기 |

## 조작법

- **장비 배치**: 하단 인벤토리의 `배치` 버튼, 또는 3D 화면의 `+ ○○ 배치` 버튼
- **케이블 연결**: 인벤토리에서 케이블 종류 선택 → 한쪽 단자 클릭 → 반대쪽 단자 클릭 (2D 배선도에서는 드래그도 가능)
- **케이블 분리**: 캔버스의 케이블 클릭 (케이블은 인벤토리로 돌아옴)
- **장비 이동 (2D 배선도)**: 장비 상단 바를 드래그
- **장비 제어**: 장비를 클릭하면 오른쪽 패널에 GAIN·EQ·페이더·뮤트·라우팅·스위처·OBS 컨트롤 표시
- **마이크 테스트**: `말하기` 버튼을 누르고 있거나 Space 키 (스테이지 3·4는 진행자가 계속 말하는 중)
- **힌트**: 단계별 힌트, 1개당 -100점. 스테이지 4에서는 2번째 힌트가 신호 추적기를 켭니다.
- **효과음**: 헤더의 스피커 아이콘 (하울링 소리 포함, 기본 꺼짐)

## 점수

스테이지마다 기본 1000점 + 시간 보너스(최대 300) − 감점(잘못된 케이블 -50, 팝 노이즈 -30, 힌트 -100).
네 스테이지를 모두 마치면 S / A / B / C 등급 수료증이 나옵니다.

## 신호 모델 (요약)

- 마이크 출력 −45 dB + GAIN → 채널 입력 레벨 (0 dB 초과 시 클리핑, 목표 −20 ~ −6 dB)
- 페이더 위치 75% = 0 dB(유니티), 100% = +10 dB, 0% = −∞
- 하울링 루프 이득 = (GAIN − 40) + 채널 페이더 + 메인 페이더 + EQ MID + 0.4 × EQ HIGH + 스피커 위치(정면 +8 / 뒤쪽 −6), 0 이상이면 하울링
