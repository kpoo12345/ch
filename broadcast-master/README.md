# 방송장비 마스터 (Broadcast Equipment Master)

음향·영상·조명·송출 장비를 **3D 현장에서 직접 설치하고 조작하며** 배우는 한국어 교육용 시뮬레이션 게임입니다.
마이크 한 대짜리 세미나실 PA부터 교회 방송실, 밴드 공연장, 강의 중계, 무대 조명(Tiger Touch), 영상 연출(Resolume), PTZ 조이스틱 운용까지 —
실제 현장에서 그대로 쓸 수 있는 신호 흐름과 트러블슈팅 감각을 익히는 것이 목표입니다.

React 19 + Tailwind CSS v4 + lucide-react로 UI를, Three.js(React Three Fiber · drei)로 3D 장소와 장비를 만들었고,
배경음악·현장 소리·효과음은 Web Audio로 실시간 합성합니다(외부 음원 파일 없음).

## 게임 모드

| 모드 | 내용 |
| --- | --- |
| **튜토리얼** | 게임이 스스로 진행합니다. "유령 손"이 케이블을 꽂고 노브·페이더를 돌리고, 카메라가 조작 지점을 따라가며 내레이션(음성)이 개념을 설명합니다. **직접 해보기**를 켜면 각 단계를 플레이어가 따라 할 때까지 기다립니다. 3개 파트: 소리의 길(PA) · 방송의 길(카메라·ATEM·OBS) · 빛과 화면(조명·미디어 서버·PTZ). |
| **교육 모드** | 50개 항목의 장비 백과. 3D 뷰어로 돌려 보고 직접 만져 보며 원리·단자·실무 팁·자주 하는 실수·퀴즈를 확인합니다. 소리 실습실(Web Audio)에서 GAIN·LOW CUT·EQ·리버브·에코를 실제로 들어 봅니다. |
| **스토리 모드** | 9개 장 · 26개 현장 미션. 장비 배치·배선·믹서 조작·스위칭·조명 큐·VJ 출력·PTZ 프리셋·숨은 고장 찾기. 막히면 단계별 힌트, 그래도 어려우면 **정답 보기**(유령 손 자동 진행 + 해설). ★1~3 평가. |
| **스튜디오 모드** | 자유 설치 모드. 장비 개수 제한 없이 카탈로그에서 꺼내 바닥·책상·무대 아무 곳에나 놓고, 이동·회전·삭제, 케이블 무제한. 선택 사항인 도전 과제 8개, 자동 저장. |

## 3D 현장

- 장소 5곳(세미나실·1인 방송실·교회·밴드 공연장·강의 중계 스튜디오) + 자유 스튜디오. 사람(발표자·찬양팀·밴드·관객), 무대·강대상·장의자·트러스 등 소품
- 8채널 아날로그/디지털 믹서: 채널마다 GAIN·LOW CUT·EQ·FX·AUX·MUTE·페이더·미터가 상태 그대로 움직이고, 채널 이름표에 연결된 소스 이름이 표시됩니다
- 케이블은 단자에서 바닥·책상 뒤로 내려가고, 무대 ↔ 음향 부스는 객석 통로를 따라 한 묶음(스네이크)으로 갑니다. 새로 꽂으면 케이블이 자라나며 유령 손이 플러그를 끼웁니다
- 조명은 실제 빛줄기와 스포트라이트, 프로젝터·LED 전광판에는 Resolume 레이어 합성 화면, OBS·멀티뷰에는 카메라별 실제 구도가 그려집니다
- 하울링 경로(스피커 → 마이크), 탈리 불빛, ON AIR 표시, 험·클리핑 상태 표시

## 시뮬레이션 엔진 (`src/game/sim.js`)

- 모든 소리 소스(마이크·무선·악기·노트북)를 케이블을 따라 추적해 채널 → MAIN/AUX/USB → 스피커·모니터·헤드폰·방송까지 레벨(dBu 근사)을 계산
- 팬텀(디지털 믹서는 입력 단자 단위), 악기 Hi-Z, DI(레벨 변환·그라운드 루프·리프트), 언밸런스드 장거리 험, 클리핑, 피드백 루프 이득
- 영상: 카메라·미디어 서버 → ATEM 입력 → PGM/PVW → USB(OBS) 또는 ETHERNET(ATEM Pro), 클린 HDMI, 조명 부족 시 어두운 화면
- 조명: DMX 체인·주소·패치 충돌·터미네이터·마이크 케이블 깜빡임, 플레이백 HTP + 프로그래머, GM·BLACKOUT
- 화면: Resolume 레이어·출력 매핑·해상도 불일치, 프로젝터/LED 전원
- PTZ: 같은 공유기·같은 IP 대역·조이스틱 카메라 목록, 프리셋, 장소별 구도 판정, 방송 중 움직임 기록
- 모든 상태 변경은 `src/game/ops.js`의 op로 처리 → 플레이어 조작·정답 자동 진행·튜토리얼·3D 유령 손이 같은 경로를 씁니다

## 실행

```bash
cd broadcast-master
npm install
npm run dev             # 개발 서버
npm test                # 엔진·스테이지 검증 (node:test)
npm run build           # dist/index.html 단일 파일
npm run build:artifact  # + dist/artifact.html
```

## 조작법

- **케이블**: 단자 클릭 → 아래 케이블 가방에서 종류 선택 → 연결할 단자 클릭 (휴대폰은 "연결표" 탭이 편합니다). 케이블을 클릭하면 분리
- **장비 조작**: 3D에서 장비 클릭(더블클릭 = 확대) 또는 "장비" 탭에서 선택
- **믹서**: 아래 "믹서 콘솔" — 노브는 위아래로 드래그, 더블클릭 = 기본값
- **말하기**: 버튼을 누르고 있거나 Space 키. "자동 말하기"로 진행자가 계속 말하게 할 수 있습니다
- **듣는 위치**: 객석 스피커 / 무대 모니터 / 헤드폰 / 방송(시청자) — 그 위치에 도착한 소리(말소리·악기·험·하울링)가 실제로 들립니다
- **보기 도구**(3D 오른쪽 위): 단자 이름, 시점 고정, 조작 따라가기, 전체 보기
- **소리**: 위쪽 음표 = 배경음악, 스피커 = 현장 소리·효과음, 말풍선 = 내레이션 음성
